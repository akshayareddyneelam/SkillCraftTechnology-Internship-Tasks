Excel Sales Dashboard

Task 01

Create a sales dashboard using Excel or Google Sheets.

Objective

- Clean the sales data.
- Create Pivot Tables.
- Show Total Sales.
- Show Profit by Category.
- Show Sales Trends over Time.
- Use charts to visualize the data.
- Use conditional formatting to highlight high and low performers.

Tools

- Microsoft Excel / Google Sheets
- Pivot Tables
- Pivot Charts
- Conditional Formatting

Final Result

A simple and clear Sales Dashboard showing important sales and profit insights.
